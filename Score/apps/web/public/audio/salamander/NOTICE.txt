Salamander Grand Piano
Samples by Alexander Holm. Yamaha C5 grand piano recordings.

MP3 distribution: Tone.js audio repository
https://github.com/Tonejs/audio/tree/efd8296360f9526e379bfbe5c1698ff54d6a1d34/salamander

The source distribution names Creative Commons Attribution 3.0:
https://creativecommons.org/licenses/by/3.0/
Its original README is included as SOURCE-README.txt.

The original author additionally declared the library public domain on 2022-03-04:
https://rytmenpinne.wordpress.com/sounds-and-such/salamander-grandpiano/

Cantelvio Score uses an unmodified subset of 17 MP3 samples (C2 through C6,
sampled every minor third). Runtime pitch shifting, gain and release envelopes
are applied. This is a compact single-layer web subset, not the full
16-velocity-layer library. SHA-256 provenance is in manifest.json.
