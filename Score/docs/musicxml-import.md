# MusicXML 导入

把 MusicXML（`.musicxml`、`.xml`、压缩的 `.mxl`）读成 ScoreDoc。代码在
`packages/core/src/io/`：`xml.ts`（小型 XML 解析器）、`zip.ts`（读 `.mxl` 的目录）、`musicxml.ts`（转换）、
`musicxml-instruments.ts`（声部 → 乐器）。决定与取舍见 [ADR 0011](adr/0011-musicxml-import.md)。

## 怎么用

- 编辑器：**打开**（或拖进窗口）选 MusicXML 文件即可。导入的乐谱是一份新的、未保存的文档，
  **保存**时另存为 `.ailegro.json`，不会写回 MusicXML 文件。没导入或做了近似的内容在提示里列出前两条，
  完整列表在浏览器控制台（`[MusicXML]`）。
- 命令行：

  ```sh
  npm run import:musicxml -- score.mxl --out out/score.ailegro.json   # 打印提示和校验问题
  npm run import:musicxml -- corpus/*.mxl --summary                    # 每个文件一行
  npm run render -- --file score.mxl --out out/                        # 导入后直接排版成 PNG
  ```

- 代码：`importMusicXml(xml, { ids, now, fileName })` → `{ doc, warnings }`；`.mxl` 先用
  `musicXmlFromBytes(bytes, inflateRaw)` 取出 MusicXML 文本（解压由平台提供：浏览器
  `DecompressionStream('deflate-raw')`，Node `zlib.inflateRawSync`）。

导入的事件、力度、和弦记号、线条都带 `source: { kind: 'import', format: 'musicxml', file }`。
相同输入、相同 id 生成器 → 相同文档；结果一定通过 `validateScore`。

## 怎么转换

- **时间**：`<divisions>` / `<duration>` 换成精确有理数（全音符为 1）；`<backup>`、`<forward>`、`<chord/>`
  移动时间游标。导出程序为了整数时值把三连音等四舍五入时（例如每四分音符 256 份），按记谱时值（音符类型、
  附点、连音比例）取准确值。
- **小节**：所有声部共用小节；小节长度取各声部内容的最大长度，与拍号不符的（弱起、不完整小节）记为
  `actualLength`。拍号、调号写在小节末尾时算下一小节的。
- **声部**：MusicXML 的声部属于整个乐器，这里的声部属于谱表（每谱表最多 4 个）。每个谱表先给“住在”
  这里的声部分配槽位（按出现顺序），再给跨谱表来访的；从不同时出现的声部可以共用一个槽位。同一声部里重叠的
  音符移到空闲声部，实在放不下才缩短前一个音（都会提示）。
- **连音线**：整个和弦都连到紧接着的同音高和弦时合并成**一个事件**（也跨小节线：一个发声的音 = 一个事件）；
  只连了部分音的和弦保留两个事件，被连的音带 `tieForward`。
- **音高**：存实际音高并保留拼法。带 `<transpose>` 的声部从记谱音高换算（音级 + 半音）；乐谱调号取不移调声部
  的多数调号，只有移调乐器时用换算后的调号。乐器的移调与目录里的乐器一致时不再单独记录。
- **乐器**：依次按 `<instrument-sound>`、声部名 / 缩写 / 乐器名（英、德、意、法常见写法）、MIDI 音色猜目录乐器；
  “Bass” 在有其他人声或有歌词时是男低音，否则是低音提琴。认不出的用钢琴并提示。多谱表乐器加花括号，
  `part-group` 变成括号 / 花括号。
- **记号**：演奏法、延长记号、装饰记号、震音（单音）、琶音、换气、小音符、倚音（附在同一声部的下一个音上）、
  力度（谱表力度）、渐强渐弱、连线（同一声部内）、八度记号、踏板、颤音线、和弦记号（`<kind>` 和 `<degree>`
  换成 AIlegro 的和弦性质，带低音）、速度（`<metronome>`、`<sound tempo>`，或速度术语）、排练号、
  反复记号、小节线样式、元信息（标题、作曲、作词、编曲、版权）、纸张大小和谱表大小。

## 没有导入的内容（都会计数提示，从不静默丢弃）

歌词、房子（1./2. 结尾）、D.C./D.S./coda/segno、滑音、两音震音、无音高打击乐、跨谱表 / 跨声部的连线、
指法、文字表情记号（速度术语以外的 `<words>`）、小节反复记号、和弦里只属于单个音的记号、超过 4 个同时
声部的多余音（并进和弦或丢弃）、`print-object="no"` 的隐藏音符（多为回放辅助）、`<opus>` 合集文件。

## 实测（music21 语料库，2026-10-03）

music21 自带的 654 个 MusicXML / `.mxl` 文件（巴赫众赞歌、贝多芬和莫扎特四重奏、舒伯特艺术歌曲、
韦伯单簧管协奏曲、拉格泰姆、中世纪经文歌、带和弦记号的流行曲谱等）全部导入，**0 个校验问题**。
最常见的提示：歌词（495 个文件）、文字表情记号（119）、找不到同音高后续音的连音线（45）、
各声部调号不一致（39，多为移调乐器或古谱）、长度与拍号不符的小节（30）、房子（26）。

和 music21 的读法逐音比较（抽 181 个文件、26.4 万个音；实际音高，连音线合并，不计倚音）：99.0% 的音
小节、小节内位置、时值、音高完全相同，147 个文件完全一致。抽查的差异（舒伯特、舒曼、贝多芬、勋伯格）都在
music21 一侧：它照搬文件里四舍五入过的三连音时值，也没有合并和弦上的连音线。

排版抽查：巴赫众赞歌 BWV 66.6（弱起、延长记号）、舒伯特《菩提树》（人声 + 钢琴、三连音、转调）、
韦伯单簧管小协奏曲（降 B 调单簧管记谱 F 大调、实际 E♭ 大调）；编辑器里拖入 `.mxl` 和 `.xml` 都能打开。
