# 编辑器与输入方式

代码：`apps/web`。启动：`npm run dev` → http://127.0.0.1:5178/

## 联合创作流程（计划，2026-10-05）

编辑器下一阶段围绕材料、范围、六组乐器和候选审阅组织，新增候选隔离、按小节或乐器接受、锁定材料预检及过期结果处理。具体职责与验收见 [Score 开源接入计划](open-source-integration-plan.md)；下文仍描述当前界面，不代表这些新功能已经完成。

## 运行方式

- **本机运行**（完整功能）：`npm install && npm run dev`，打开 http://127.0.0.1:5178/ 。
- **GitHub Pages 网页试用**：静态编辑器可编辑、新建、打开 `.ailegro.json` / MusicXML、
  播放和导出 MIDI / PDF / SVG；顶栏「示例」提供钢琴、室内乐和管弦乐曲谱。
  `?demo=continue` 打开可编辑的钢琴示例，并使用独立演示草稿，不覆盖普通编辑草稿。
  此网页不托管模型，不探测访问者电脑的服务，也不上传 PDF、图片或录音；
  AI 生成、和声分析、识谱和扒谱需要下载项目并在本机启动编辑器和 AIlegro 服务。
  请求 / 结果文件交换仍可用。部署时设 `VITE_STATIC_PREVIEW=true`（自定义域名也适用）；
  `*.github.io` 自动采用相同行为。返回项目主页的链接使用相对路径，支持 `/Cantelvio/score/`。
- **claude.ai 上的托管版**（免安装试用，作者私有的 artifact 链接）：同一份构建产物发布成 claude.ai artifact。
  在那里：保存 / 导出由查看器弹出确认后下载；不能打印；**连不到本机的 AIlegro 服务**（浏览器沙盒禁止），
  所以“直接生成”只在本机运行时可用，文件交换（导出请求 → 运行脚本 → 导入结果）两边都能用。
  自动保存只存在于这个浏览器里。发布方式：`npm run build` 后把 `apps/web/dist` 的页面、`assets/` 和
  `audio/` 作为 artifact 的文件发布（`src/host.ts` 负责识别查看器环境）。

### 曲谱视图

顶栏下拉框可以选择：

- **页面视图**：按纸张尺寸分行分页，适合检查印刷版面。
- **无缝模式**：曲谱按窗口宽度换行，连续向下滚动；没有页码、页面边框、阴影或页间空隙。
  调整缩放、窗口尺寸或侧栏时自动重新换行，鼠标滚轮和触屏滑动都可滚动。
  小节编号保留；选音、输入、范围选择、输入光标和播放线使用相同的乐谱数据。
- **横向连续**：所有小节排在一行，横向滚动，保留原连续视图的用法。

切换视图不修改乐谱、撤销记录或已保存的换行/换页提示。无缝模式把换页提示显示为普通换行。
PDF / SVG 导出仍分页；浏览器打印前临时排成页面视图，打印结束后恢复所选视图。

## 两种模式

- **选择模式**（默认）：点音符选中（Shift 多选），点小节空白处选中小节（Shift 扩展范围），
  点休止符选中休止符。选中音符时按时值键会**改变时值**。
- **音符输入模式**（`N`）：光标（按声部着色的竖条）显示输入位置。字母键输入音符，
  鼠标点击谱表直接放音（鼠标处显示阴影音符和加线）。写到乐谱末尾会自动加小节。

## 小键盘（浮动窗口）

参考 Sibelius 的 Keypad 和 MuseScore 的面板：一个可以拖动的小窗口（拖标题栏），`K` 或顶栏“小键盘”
打开/关闭，`▾` 收起成标题栏，`Alt` + `1`–`6` 切换标签页。位置、标签页和开关状态记在本浏览器里。
手机上它停靠在屏幕底部。点按钮不会抢走键盘焦点，点完可以继续打字输入。

| 标签页 | 内容 |
| --- | --- |
| 常用 | 音符输入开关、时值（64 分到二全音符）、附点 / 双附点、休止、延音线、♭ ♮ ♯、三连音、声部 1–4 |
| 更多 | 短倚音 `/`、长倚音 `Alt+/`、十六分 / 三十二分倚音、小音符（提示音大小）、重降 / 重升、2–7 连音、符干向上 / 向下 / 自动、翻转 `X` |
| 演奏 | 断音、顿音、保持音、重音、强重音、泛音、闭音 / 开音、巴托克拨弦、上弓 / 下弓、三种延长记号、换气、停顿号 |
| 装饰 | 颤音、顺波音、逆波音、回音、逆回音；琶音（普通 / 向上 / 向下）；震音 1–4 道 |
| 线条 | 连线 `S`、渐强 `<`、渐弱 `>`、颤音线、8va / 8vb / 15ma / 15mb、踏板（Ped. * / 括线） |
| 力度 | ppp … fff、fp、sf、sfz、sffz、fz、rf、rfz、sfp |

规则（MuseScore 的用法）：

- 按钮作用于**选中的音符**；输入模式下作用于**刚输入的音**。选中的音已经带有的记号会高亮，再点一次去掉
  （选中多个音时，只要有一个没有就是添加）。延长记号三选一，上弓/下弓、闭音/开音二选一。
- 选中音符时时值按钮会**改时值**；选中的是倚音时改的是倚音的时值，主音不变。按钮显示所选音的时值。
- **倚音**加在选中音的前面，音高与它相同；新加的倚音被选中，可以直接按字母或 ↑/↓ 改音高、按时值键改时值。
  选中倚音再加倚音，会加在它后面。
- **线条**：选中几个音 → 从第一个到最后一个（只选一个音时，连线连到下一个音）；选中小节范围 →
  覆盖整个范围（连线在每个谱表、每个声部上各一条）。踏板总是放在乐器最下面的谱表。
  同类的线条（同一谱表上的八度线、渐强渐弱……）重叠时，新的替换旧的重叠部分。
- **输入模式下画线条**（Sibelius 的方式）：输入一个音，按线条键，线条从这个音开始，之后每输入一个音或
  休止符它就**跟着延长**；再按同一个键、按 `Esc` 或退出输入模式结束。连线要等第二个音才出现。
  以下情况线条自动结束，音照常输入：光标移回线条开始之前、线条会碰上下一个同类线条、它的音或乐器被删、
  撤销 / 重做；渐强渐弱在下一个力度记号处结束（力度加在刚输入的音上，渐强停在它前面）。
- 选中的线条和力度记号是“标记选择”：`Delete` 删除；这时按 `N` 或字母从它所在的位置开始输入。

## 快捷键（沿用 MuseScore 习惯）

| 键 | 作用 |
| --- | --- |
| `N` | 进入/退出音符输入 |
| `1`–`8` | 时值：64 分、32 分、16 分、8 分、**`5` = 四分**、二分、全音符、二全音符 |
| `.` | 附点 |
| `A`–`G` | 输入音符（按调号和最近的八度；移调乐器按记谱音高） |
| `Shift` + `A`–`G` | 在刚输入的和弦上方加一个音 |
| `0` | 休止符 |
| `+` 或 `T` | 延音线：输入模式下输入同音并连起来；选择模式下切换选中音的连线 |
| `↑` / `↓` | 半音升降（按调号拼写） |
| `Ctrl/⌘` + `↑` / `↓` | 升降八度 |
| `←` / `→` | 移动光标 / 选择上一个、下一个音 |
| `Delete` / `Backspace` | 删除选中的音；选中小节时清空内容 |
| `Ctrl` + `3` | 三连音（Mac 上按 Control+3；⌘3 会被浏览器用来切换标签页） |
| `Ctrl/⌘` + `Alt` + `1`–`4` | 切换声部 |
| `Shift` + `S` / `V` / `N` / `O` / `H` | 断音 / 重音 / 保持音 / 强重音 / 延长记号 |
| `S` | 连线（选中的音；输入模式下从刚输入的音开始画） |
| `<` / `>` | 渐强 / 渐弱 |
| `Ctrl/⌘` + `Alt` + `O`（`Shift`：8vb） | 高八度 8va |
| `/`（`Alt` + `/`） | 短倚音（长倚音） |
| `X` | 翻转符干 |
| `K` | 打开 / 关闭小键盘；`Alt` + `1`–`6` 切换它的标签页 |
| `Ctrl/⌘` + `B` | 末尾加一小节（`Shift` 加 4 小节） |
| `Space` | 播放 / 停止（从选中处开始） |
| `Ctrl/⌘` + `Z` / `Y`（或 `Shift+Z`） | 撤销 / 重做（选择和光标一起恢复） |
| `Ctrl/⌘` + `S` | 保存（`Shift`：另存为） |
| `Ctrl/⌘` + `O` | 打开 |
| `Esc` | 结束正在画的线条 / 退出输入 / 取消选择 |

Mac 上带 `Alt`（Option）的快捷键按键位识别（Option 会改变打出的字符）。

在输入框、下拉框、文本框里打字时，快捷键不生效；对话框打开时也不生效。

## 侧栏面板

- **AIlegro**：任务、从第几小节、小节数（选中小节范围会自动填入）、可用乐器组、给定材料所在声部、
  和声方式、采样参数；“本机 AIlegro 服务”一键生成，或导出请求 / 导入结果 / 导出乐谱记录；
  “待审阅的 AI 建议”按生成批次接受或拒绝。见 [ailegro-integration.md](ailegro-integration.md)。
- **乐器**：改名和缩写、移除（二次确认）、添加乐器（自动按管弦乐总谱顺序插入）。
- **文字输入**：在光标或选中处写入文字记谱（`Ctrl/⌘ + Enter`），见 [text-notation.md](text-notation.md)。
- **属性**：标题/副标题/作曲；所选小节的调号（大调/小调）、拍号（改拍号会重新划分小节线，音符的
  绝对位置不变）、速度标记、排练号、小节线、之后换行/换页；所选位置的和弦记号（根音、性质、低音）、
  力度记号、谱号。

## 文件

乐谱文件是 `.ailegro.json`（规范格式，适合放进 git，见 [score-model.md](score-model.md#文件格式-ailegrojson)）。

- **Chrome / Edge（本机运行）** 用 File System Access：**打开**弹出系统的文件对话框；之后**保存**直接写回
  这个文件，不再询问；**另存为**选新的位置和名字；**打开 ▾** 列出最近打开或保存过的 8 个文件
  （文件句柄存在本浏览器的 IndexedDB 里，第一次重新打开时浏览器会请求权限）。
- **Safari、Firefox、claude.ai 托管版**没有这个接口：保存 = 下载文件（托管版由查看器弹出确认），
  打开 = 选择文件。没有“最近打开”。
- 把 `.ailegro.json` **拖进窗口**任何地方就会打开（Chrome 里拖进来的文件之后也能直接保存回去）。
- **MusicXML**（`.musicxml`、`.xml`、`.mxl`）用同样的方式打开或拖进来：导入成一份新的未保存乐谱，
  保存时另存为 `.ailegro.json`，不会写回 MusicXML。没导入或近似处理的内容（歌词、房子等）在提示里列出前两条，
  完整列表在浏览器控制台。转换规则见 [musicxml-import.md](musicxml-import.md)。
- **PDF / 扫描图片**（PDF、PNG、JPG、TIFF）和**录音**（WAV、MP3、FLAC、OGG、M4A、AIFF）也可以打开或拖进来，
  前提是本机 AIlegro 服务在运行（`npm run ailegro:serve`，[try-it.md](try-it.md)）：服务在后台识谱（Audiveris，
  [pdf-import.md](pdf-import.md)）或扒谱（MuScriptor + AIlegro，[audio-import.md](audio-import.md)），
  左下角显示进度、可以取消，完成后作为新的未保存乐谱打开；这期间可以继续编辑当前乐谱，打开结果前有未保存的
  修改会先问。选项在 AIlegro 面板“从 PDF 或录音开始”里。没有服务时用命令行 `npm run import:pdf` 或 AIlegro 的
  两步脚本，再打开结果。
- 新建、打开、换示例之前，如果有未保存的修改，会问“保存 / 不保存 / 取消”。选“保存”且需要先弹出保存对话框时，
  保存完会再问一次“继续打开吗？”——浏览器只允许在一次点击之后打开文件对话框，保存对话框已经用掉了那次点击。
- 关闭或刷新页面时，如果打开的文件有未保存的修改，浏览器会提醒。
- 保存的是按下保存那一刻的乐谱：写文件期间又做的修改仍然算“未保存”。
- **自动保存**：每次修改后约 0.8 秒保存在本浏览器（localStorage），下次打开自动恢复。
  这只是便利功能，不是文件——重要的乐谱请保存成文件。
- **导出菜单**：MIDI、PDF、SVG。
- **MIDI**：按整谱回放的实际音高、速度、力度、连音和奏法导出；每个声部一条轨道，保留 GM 音色，打击乐用第 10 通道。
  当前一个文件最多 15 个有音高的声部，超出会显示导出失败；更大的编制需增加 MIDI 多端口支持。
- **PDF**：使用现有排版的矢量页面，尺寸与纸张设置一致；嵌入中文字体，保留可提取的文字。
- **SVG**：每页一个 SVG，毫米尺寸，可直接印刷或导入排版软件。
- **打印 / PDF**：浏览器打印，只打印乐谱页面（可“存储为 PDF”）。

## 回放

- Web Audio，按乐谱的速度标记、连线、力度调度；从选中处开始，播放线跟随。
- 播放线使用音频时钟，在音符之间及最后一个音符到小节线之间连续前进；
  长音或整小节休止也持续移动，三种曲谱视图采用相同的时间定位。
- 首选 SpessaSynth 与本地 MuseScore General SoundFont，按各声部 GM 音色回放，并支持打击乐映射。
  首次加载音色后开始播放；按停止会取消已经排程的音符，加载期间也可以停止。
- 音色加载失败时，钢琴使用既有 Salamander 采样，其他乐器使用合成音色。
  第三方资源及许可证见 [third-party-notices.md](third-party-notices.md)。
- 点选或输入音符时会预听该音（使用该乐器的音色）。

## 手动检查清单（改编辑器后过一遍）

1. 打开示例钢琴曲：页面、括号、调号、拍号正常；状态栏显示“1 件乐器 · 8 小节”。
2. 点第一个音 → 按 `N` → `C D E`，再 `Shift+G`；撤销 4 次回到原样，重做一次。
3. 选中一小节 → `Delete` 清空；`Ctrl+B` 加小节。
4. 新建弦乐四重奏；乐器面板添加长笛（应插在最上面）。
5. 文字输入写入 `c4 d e f | g1`；属性面板改速度、加和弦记号。
6. AIlegro 面板：`--mock` 服务器“连接”→“直接生成”→ 出现蓝色音符和待审阅条目 → 接受 / 拒绝。
7. 保存 → 打开刚保存的文件 → 内容一致；再改一个音按 `Ctrl+S`，不再弹对话框；“打开 ▾”里有这个文件；
   有修改时打开别的文件会先问；把文件拖进窗口能打开。导出 SVG；播放 / 停止无报错。
8. 小键盘：选两个音加颤音和断音（按钮高亮）；线条页加连线和 8va；`N` 输入 `C`、按 `<`、再输入 `D E F`，
   渐强跟着变长，`Esc` 结束；选一个音按 `/` 加倚音，按字母改音高、按 `3` 改成十六分；力度页加 mf。
   拖动小键盘、收起、`K` 关闭再打开；手机宽度下停靠在底部。
9. 切换 EN、深色模式、三种曲谱视图、缩放，界面不溢出；无缝模式在桌面、平板、手机尺寸检查
   向下滚动、点选后半段小节、输入光标跟随及侧栏开关后的换行；打印后仍回到无缝模式。

浏览器自动化脚本（Playwright）目前在开发者本机/云端会话里使用，尚未加入仓库（路线图 `M2-WEB-06`）。
