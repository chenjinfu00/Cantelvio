# 编辑器与输入方式

代码：`apps/web`。启动：`npm run dev` → http://127.0.0.1:5178/

## 界面

```text
┌ 顶栏：新建 · 打开 · 保存 · 示例 · 导出 SVG · 打印/PDF │ 撤销 重做 │ 播放 │ 实际音高 · 连续视图 · 缩放 · 中/EN
├ 工具条：音符输入(N) │ 时值 64分…全音符 · 附点 │ 休止 · 延音线 · 三连音 │ ♭ ♮ ♯ │ 演奏法 │ 声部 1–4 │ 小节
├───────────────────────────────────────────────┬───────────────┬──┐
│ 乐谱（页面视图 / 连续视图）                     │ 侧栏面板       │标│
│                                                │ AIlegro / 乐器 │签│
│                                                │ 文字输入 / 属性 │  │
├ 状态栏：模式 · 位置（小节/拍/声部）· 当前时值 · 乐器数/小节数 · 自动保存 · 快捷键
```

- 乐谱页面始终是白纸黑字；界面跟随系统浅色/深色主题。
- AI 建议显示为**蓝色**；无法精确记写的时值显示为橙色；选中的音符为亮蓝。

## 两种模式

- **选择模式**（默认）：点音符选中（Shift 多选），点小节空白处选中小节（Shift 扩展范围），
  点休止符选中休止符。选中音符时按时值键会**改变时值**。
- **音符输入模式**（`N`）：光标（按声部着色的竖条）显示输入位置。字母键输入音符，
  鼠标点击谱表直接放音（鼠标处显示阴影音符和加线）。写到乐谱末尾会自动加小节。

## 快捷键（沿用 MuseScore 习惯）

| 键 | 作用 |
| --- | --- |
| `N` | 进入/退出音符输入 |
| `1`–`8` | 时值：64 分、32 分、16 分、8 分、**`5` = 四分**、二分、全音符、二全音符 |
| `.` | 附点 |
| `A`–`G` | 输入音符（按调号和最近的八度；移调乐器按记谱音高） |
| `Shift` + `A`–`G` | 在刚输入的和弦上方加一个音 |
| `0` | 休止符 |
| `+` 或 `T` | 延音线：输入模式下输入同音并连起来；选择模式下切换选中音的连线 |
| `↑` / `↓` | 半音升降（按调号拼写） |
| `Ctrl/⌘` + `↑` / `↓` | 升降八度 |
| `←` / `→` | 移动光标 / 选择上一个、下一个音 |
| `Delete` / `Backspace` | 删除选中的音；选中小节时清空内容 |
| `Ctrl` + `3` | 三连音（Mac 上按 Control+3；⌘3 会被浏览器用来切换标签页） |
| `Ctrl/⌘` + `Alt` + `1`–`4` | 切换声部 |
| `Shift` + `S` / `V` / `N` / `O` / `H` | 断音 / 重音 / 保持音 / 强重音 / 延长记号 |
| `Ctrl/⌘` + `B` | 末尾加一小节（`Shift` 加 4 小节） |
| `Space` | 播放 / 停止（从选中处开始） |
| `Ctrl/⌘` + `Z` / `Y`（或 `Shift+Z`） | 撤销 / 重做（选择和光标一起恢复） |
| `Ctrl/⌘` + `S` | 保存 `.ailegro.json` |
| `Esc` | 退出输入 / 取消选择 |

在输入框、下拉框、文本框里打字时，快捷键不生效；对话框打开时也不生效。

## 侧栏面板

- **AIlegro**：任务、从第几小节、小节数（选中小节范围会自动填入）、可用乐器组、给定材料所在声部、
  和声方式、采样参数；“本机 AIlegro 服务”一键生成，或导出请求 / 导入结果 / 导出乐谱记录；
  “待审阅的 AI 建议”按生成批次接受或拒绝。见 [ailegro-integration.md](ailegro-integration.md)。
- **乐器**：改名和缩写、移除（二次确认）、添加乐器（自动按管弦乐总谱顺序插入）。
- **文字输入**：在光标或选中处写入文字记谱（`Ctrl/⌘ + Enter`），见 [text-notation.md](text-notation.md)。
- **属性**：标题/副标题/作曲；所选小节的调号（大调/小调）、拍号（改拍号会重新划分小节线，音符的
  绝对位置不变）、速度标记、排练号、小节线、之后换行/换页；所选位置的和弦记号（根音、性质、低音）、
  力度记号、谱号。

## 文件

- **保存** 下载 `.ailegro.json`（规范格式，适合放进 git）；**打开** 读取 `.ailegro.json`。
- **自动保存**：每次修改后约 0.8 秒保存在本浏览器（localStorage），下次打开自动恢复。
  这只是便利功能，不是文件——重要的乐谱请保存成文件。
- **导出 SVG**：每页一个 SVG，毫米尺寸，可直接印刷或导入排版软件。
- **打印 / PDF**：浏览器打印，只打印乐谱页面（可“存储为 PDF”）。

## 回放

- Web Audio，按乐谱的速度标记、连线、力度调度；从选中处开始，播放线跟随。
- 钢琴类乐器用 Salamander Grand Piano 采样（17 个采样，按小三度，运行时移调）；其他乐器暂时用
  按 GM 音色族的简单合成音色。打击乐用合成鼓声。
- 点选或输入音符时会预听该音（使用该乐器的音色）。

## 界面文字

所有界面文字在 `src/i18n/index.ts`，中文与英文两份（类型检查保证两份键一致）。
“AIlegro” 在界面里把 **AI** 用强调色显示，避免在无衬线字体里看成 “Allegro”。

## 手动检查清单（改编辑器后过一遍）

1. 打开示例钢琴曲：页面、括号、调号、拍号正常；状态栏显示“1 件乐器 · 8 小节”。
2. 点第一个音 → 按 `N` → `C D E`，再 `Shift+G`；撤销 4 次回到原样，重做一次。
3. 选中一小节 → `Delete` 清空；`Ctrl+B` 加小节。
4. 新建弦乐四重奏；乐器面板添加长笛（应插在最上面）。
5. 文字输入写入 `c4 d e f | g1`；属性面板改速度、加和弦记号。
6. AIlegro 面板：`--mock` 服务器“连接”→“直接生成”→ 出现蓝色音符和待审阅条目 → 接受 / 拒绝。
7. 保存 → 打开刚保存的文件 → 内容一致；导出 SVG；播放 / 停止无报错。
8. 切换 EN、深色模式、连续视图、缩放，界面不溢出。
