# 小节末拍播放线修复验证（2026-10-05）

## 原因与修复

播放覆盖层只在相邻音符起点之间插值。经过小节最后一个起点后，缺少后续定位点，
进度线停在该音符上，直到下一小节开始才跳转。

现在使用排版引擎的时间到横坐标转换，把小节线作为最后的插值终点。
音频时钟的浮点位置直接用于显示，不量化成音符时值。
小节起始时间按文档缓存，避免每一帧、每一次小节搜索都重新遍历整谱。
本次没有改动音频调度、音符数据或文件格式。
