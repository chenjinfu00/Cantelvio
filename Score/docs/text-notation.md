# 文字记谱输入（AIlegro text notation v0）

代码：`packages/core/src/io/text.ts`（`parseText`、`textToCommands`）。编辑器：侧栏“文字输入”。
灵感来自 LilyPond 的相对音高模式，但更简单，并且**默认按调号解释音名**（像键盘输入一样）。

用途：快速输入一段音乐；测试与示例乐谱（`core/src/samples` 全部用它写成）；
让语言模型（包括将来的 AIlegro 文字接口）直接写出可读的乐谱。

## 例子

```text
c4 d e f | g2 g | a4 a a a | g1          % 小星星的开头（% 后是注释）
c'4 d, e8. f16 g4~ g8 r8 <c e g>2 R      % 八度记号、附点、延音线、休止、和弦、整小节休止
3{ c8 d e } f#4 bb4 en4                  % 三连音；升、重降、还原
5:4{ c16 d e f g } a4                    % 五连音，显式比例
```

## 语法

| 写法 | 含义 |
| --- | --- |
| `c d e f g a b` | 音名（大小写均可）。默认**跟随调号**：G 大调里 `f` 是 F#。 |
| `#` `##`（或 `x`） `b` `bb` | 升、重升、降、重降：`f#` `cx` `bb`（降 B）`ebb` |
| `n` | 强制还原：G 大调里 `fn` 是 F 本位 |
| `'` `,` | 升高 / 降低一个八度，可叠加：`c''`、`g,,` |
| `1 2 4 8 16 32 64 128` | 时值：全、二分、四分、八分……写在音名后：`c4`、`d8` |
| `.` | 附点，可多个：`c4.`、`d2..`（附点前必须写时值） |
| （不写时值） | 沿用上一个音的时值 |
| `~` | 延音线连到下一个音：`c2~ c8` |
| `r` | 休止符，可带时值：`r4`、`r8.` |
| `R` | 休止到本小节结束 |
| `<c e g>2` | 和弦，时值写在 `>` 后面 |
| `3{ … }` | 连音：3 个音占 2 个的时间。默认比例：2:3、3:2、4:3、5:4、6:4、7:4、9:8 |
| `5:4{ … }` | 显式比例 |
| `|` | 小节检查（可选）：位置不在小节线上时给出警告 |
| `% …` | 注释到行尾 |

## 八度怎么定

- 第一个音：靠近**光标处这个声部的前一个音**；没有前一个音时，靠近谱号的中线
  （高音谱号 B4、低音谱号 D3）。
- 之后每个音都放在离前一个音最近的八度（相差不超过四度）；`'` / `,` 在此基础上再移八度。
- 和弦里，每个音参照和弦里的前一个音；和弦之后的参照音是**和弦的第一个音**。

## 写进乐谱时

- 从光标（输入模式）或选中的音 / 小节开始写，**覆盖**原有内容（和键盘输入一样）。
- 超过乐谱末尾会自动追加小节（`extend: true`）。
- 跨小节线的音写成**一个**事件，显示时自动连线。
- 连音组跨过小节线时不建立连音框（给出警告），时值仍然正确。
- 音名按**实际音高**解释；移调乐器（如降 B 单簧管）的记谱音高由软件推导。
  （按记谱音高输入是路线图任务 `M2-CORE-03`。）

## 错误与警告

- 语法错误抛出 `TextNotationError`，消息里带字符位置：`unexpected "x" (at character 12)`、
  `unterminated chord`、`a dot needs an explicit duration (e.g. 4.)`、`nested tuplets are not supported yet`。
- 警告（不阻止写入）：小节检查失败、超出乐谱被截断、连音跨小节线。

## 将来

- 声部切换（`\voice 2` 之类）、力度和演奏法（`c4-. d->`）、连线 slur、歌词。
- 绝对八度模式（给语言模型用更稳）。
- 从乐谱导出为文字记谱（往返），用于 AI 对话里的“把这几小节给我看”。
