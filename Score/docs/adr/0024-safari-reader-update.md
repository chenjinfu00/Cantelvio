# 0024. Safari 阅读器缓存更新入口

- 状态：已接受
- 日期：2026-10-25

## 背景

旧阅读器的Service Worker会把带不同查询参数的导航都映射到缓存中的index.html。它完成整套离线资源下载后才激活新版，因此仅发布程序或更换链接参数不能保证Safari立刻显示新版。

## 决定

Score的谱库入口先进入位于旧阅读器作用域之外的`score/update.html`。更新页联网核对并完整读取新版HTML、脚本和样式，成功后仅注销scope精确等于原阅读器根路径的Service Worker，再进入原`score/library/`路径。已使用当前版本时直接进入；失败保留原注册并提供重试。遇到其他标签重建注册时不继续跳转。

不清除IndexedDB、localStorage、CacheStorage或设备文件，不改变曲谱SHA、批注、书签、目录及离线PDF路径。其他阅读器的注册不受影响；不请求浏览器全屏。更新程序不预取曲谱、音频或字体。

## 后果

Safari可以通过固定的新入口跳出旧程序缓存，保留原有阅读数据。更新期间需要联网。主屏幕应用的独立存储和启动方式另行验证，不把Safari验证当作真机已安装应用验收。
