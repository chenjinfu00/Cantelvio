# 0014. 回放与导出使用独立浏览器库

- 状态：已接受
- 日期：2026-10-04

## 背景

编辑器已有实际音高的播放时间线和自研 SVG 排版，需要管弦乐音色、MIDI 文件和准确尺寸的矢量 PDF。

## 决定

在 web 层接入 SpessaSynth、MuseScore General、Tone.js MIDI、svg2pdf.js 和 jsPDF。
MIDI 和回放都从 `buildPlayback` 读取实际音高、力度及奏法；PDF 读取既有 `layoutScore` 和 `renderPageSvg`。
不将这些浏览器依赖引入 core、engraving 或协作命令数据。

## 后果

音色和中文字体成为需随发布保留许可证的静态资源，按需加载。停止回放销毁工作线程合成器，取消未来音符。
音色失败有原回放兜底。PDF 使用字体子集；当前各文本字重共用常规字体。
MIDI 单端口有 15 个有音高声部的上限，更多声部需要另行实现多端口。

## 考虑过的其他方案

更换整个排版引擎会扩大迁移范围，也不能解决实际音高和协作问题；继续只用合成音色无法满足管弦乐回放。
浏览器打印继续保留，但独立 PDF 导出可以固定尺寸和嵌入中文字体。
