# 0016. 无缝曲谱使用纵向长画布

- 状态：已接受
- 日期：2026-10-05

## 背景

用户需要正常换行、没有页码和页间空白、连续向下滚动的曲谱。既有 `continuous` 模式是一行横向长谱，
直接改变其含义会失去已有的大总谱编辑方式。

## 决定

增加独立的 `seamless` 排版模式。沿用纸张模式的横向分行与记谱，在同一画布上按自然行距纵向排列所有谱行。
编辑器测量可用宽度，按当前缩放转换成毫米参数；排版包仍是纯函数。视图选择不写入 ScoreDoc，也不修改文件格式。
分页、无缝和横向连续通过顶栏下拉框选择。打印临时采用分页，PDF / SVG 导出继续采用纸张布局。

## 后果

同一套几何信息继续支持点选、输入光标和播放线。无缝视图忽略换页的纵向留白，但保留该处换行和文档提示。
很窄的窗口下，无法拆分的密集小节允许横向滚动，完整保留记谱。当前仍对整谱重新排版，增量排版任务继续独立推进。

## 考虑过的其他方案

只用 CSS 隐藏纸张阴影和间隔仍会留下页内留白，不能实现自然行距；把旧连续模式改成纵向会丢失横向编辑入口。
另建曲谱模型或把画布宽度写进文档会让同一乐谱在不同设备上互相覆盖显示设置。
