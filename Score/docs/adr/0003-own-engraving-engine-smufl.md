# 0003. 自研排版引擎 + SMuFL（Bravura）

- 状态：已接受
- 日期：2026-10-01

## 背景

需要：钢琴到交响乐总谱的排版、编辑器命中测试用的几何信息、AI 建议的专门样式、确定性输出
（快照测试、视觉对比）、对大总谱做增量排版的能力。

## 决定

- 自己写排版引擎（`packages/engraving`），纯函数 `(doc, options) → layout → SVG`。
- 字形使用 SMuFL 标准的 **Bravura** 字体（SIL OFL 1.1）：构建时把需要的字形轮廓、外框、锚点
  生成为 TypeScript 数据，运行时不加载字体，SVG 自包含。
- 版式常数集中在 `STYLE`，单位是谱表间距。

## 后果

- 完全掌控：总谱括号、移调记谱、AI 建议样式、几何导出、未来的增量排版都由我们决定。
- 工作量大：连线、歌词、多声部碰撞等要逐步实现（见路线图 M2-ENG）。
- 输出确定，CI 可以渲染示例并上传图片供审阅。

## 考虑过的其他方案

- **VexFlow**：适合单行或简单乐谱，总谱分行分页、对齐需要大量自行实现，几何信息不完整。
- **Verovio**（C++/WASM，MEI）：排版质量高，但模型是 MEI，编辑需要往返转换，增量排版和自定义样式
  困难，WASM 体积大。可以作为将来的“导出对照”工具。
- **OpenSheetMusicDisplay**：基于 VexFlow 的 MusicXML 显示器，侧重显示而不是编辑。
