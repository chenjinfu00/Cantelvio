# 0023. 全窗口谱库与触屏菜单

- 状态：已接受
- 日期：2026-10-24

## 决定

Score 设备谱库继续复用 Stage 阅读器。谱库铺满当前页面窗口，点击入口不请求浏览器或系统全屏；文件夹选择、刷新与关闭放在标题行。作曲家和体裁在左侧逐级展开，右侧只显示可点击的作品标题。作品卡片移除作者、体裁、版本数量等说明；版本切换保留在打开后的阅读工具内。

界面使用肖邦、莫扎特、贝多芬、巴赫等常用名；原始目录、完整姓名、搜索材料、作品键和版本偏好键保持不变。

单选菜单使用保留原生 select 为状态来源的触屏增强层，支持点按、按住滑动后松手选择、滑出取消、滚动和键盘。动态选项、程序赋值、隐藏/禁用状态仍由原生控件决定。毛玻璃遵循当前主题，提供实色和减少透明度回退；谱纸、音符和批注不改变。

## 后果

分类与作品无需在主区域反复切换，辅助说明移入设置或指南。较旧浏览器可继续使用无 Popover 的菜单定位回退。屏幕尺寸模拟不替代 iPad 真机手势及文件夹权限验证。

发布检查覆盖阅读器回归、浏览器交互与平板尺寸；iPad真机手势与文件夹权限由后续试用核对。
