# 0007. 记号挂在事件上，倚音属于主音，线条放在全局 `spanners` 列表

- 状态：已接受
- 日期：2026-10-02

## 背景

文件格式 v1 只有音符、休止、连音、力度记号和少量演奏法。编辑器需要 Sibelius / MuseScore 常用的记号：
连线（slur）、渐强渐弱、八度记号、踏板、颤音线、装饰记号、震音、琶音、换气、小音符和倚音。
新模型必须保持已有的规则：一个发声的音 = 一个事件、事件有正的时值且同一声部不重叠、稳定 id、
确定性命令和撤销、逐行可 diff 的文件，以及给 AIlegro 的发声音高。

## 决定

1. **事件上的记号**（演奏法、装饰记号、震音、琶音、小音符、换气）是 `NoteEvent` 上的可选字段，
   缺省 = 没有。它们跟着事件走，不需要另外的 id。
2. **倚音属于它前面的主音**：`NoteEvent.graces` 是 `GraceNote` 列表（各有 id，音符和普通音符一样带 id），
   不占小节时间。回放时“在拍上”从主音借时间。
3. **线条放在 `doc.spanners` 一个全局列表里**：连线按**事件 id** 锚定（`from` / `to`），跟着音符移动、
   改时值；渐强渐弱、八度记号、踏板、颤音线按**时间**锚定（`MeasureAnchor` 的 `start` / `end`，
   覆盖 `[start, end)`，`end` 存在包含最后被覆盖时刻的小节里）。
4. **八度记号只影响显示**：音高仍然是发声音高；排版把线内的音写低（高）八度，鼠标输入时加回八度。
5. **悬空线条清理**：每个命令执行后，端点事件消失的连线、小节或谱表消失的线条在**同一步**里删除
   （第二次 `produceWithPatches`，两组补丁连在一起，撤销时一起恢复）。删小节、改拍号、清空范围、
   删除乐器时，时间线条由对应命令重新计算。
6. 文件格式升到 **v2**；v1 文件打开时迁移（补一个空的 `spanners`），保存为 v2。

## 后果

- 已有的按时间查询（事件不重叠、`eventsOverlapping`、回放、导出）完全不用改：倚音不是事件。
- 改时值、覆盖输入、移动音符时连线自动跟着走；线条和记号都有 id，AI 补丁和将来的协作可以直接引用。
- 每个线条在文件里一行，`git diff` 仍然清楚。
- 代价：时间线条在删小节、改拍号时需要维护（`spannersAfterMeasureDelete`、`spannersAfterRebar`）；
  连线只能连同一谱表、同一声部的两个事件（跨谱表 / 跨声部连线、连到倚音的连线以后再加）；
  倚音不能单独带演奏法；八度记号的显示偏移让鼠标输入和延音线配对多了一步（延音线按发声音高配对）。

## 考虑过的其他方案

- **倚音作为零时值事件**（MusicXML 的做法）：破坏“时值为正、互不重叠”的不变量，几乎每个按时间的查询
  都要特殊处理。
- **线条按小节存放**（像力度记号那样放在 `StaffMeasure` 里）：跨小节的线条要拆段，删改小节更麻烦。
- **连线按时间锚定**：音符改时值或被覆盖时连线不跟着走；Sibelius 和 MuseScore 都把连线挂在音符上。
- **八度记号改写存储的音高**：违反“存发声音高”的规则，AIlegro 导出和回放都会出错。
