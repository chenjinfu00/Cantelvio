## 0. 这个节目是什么

PowerPoint Karaoke：**演讲者事先没看过任何一页**，现场即兴。

- **不写演讲者备注。** 所有提示直接印在页面上，被观众看见是设计的一部分。
- 观众假定没有音乐基础；演讲者假定有基础乐理和凝聚态背景。
- 10 分钟，10 页。
- 页 9 的现场演示在**我们自己开发的 web 应用**里做，不在幻灯片里（见第 2 节）。

**结构是一个诱饵**：前 3 页是一场货真价实的凝聚态 seminar，第 4 页用演讲者自己刚做完的一个合法操作把他推下悬崖；到页 7 才揭晓，那块等距键盘本身就是 Kitaev 的蜂窝，每个 plaquette 里放了一个键。

## 1. 最高原则：少字、多图、多公式 ★

**每一页的默认状态是一张图。文字只负责把图点透，不负责讲解。** 一页讲清一件事，讲清就停。

| 元素 | 上限 |
|---|---|
| 标题 | ≤ 10 词，一行 |
| 页面正文（不含图内标签和公式） | ≤ 40 词，**目标 25 词**，绝不超过两行 |
| 卡片正文 | ≤ 15 词 |
| 图 + 公式占版面 | ≥ 55% |
| 每页 | 至少一张图**或**一个公式 |

改写优先级：

```
一句话   →   一条图内标注   →   一个公式   →   删掉
```

**允许写整句的只有三处**：每页最多一句收尾句；页脚的一句小字声明；页 9 给演讲者的指令。

### 1.1 公式就是内容（页 5、6 是全场的公式核心）

和弦形状和和声进行的公式**必须完整、对齐、可以逐个音核对**，不许为了好看删减。统一记法：

**罗马数字三行格式**（上：功能；中：和弦；下：变换及变动的音）：

```
 I       vi       IV        V         I
 C   →   a   →    F    →    G    →    C
     R        L      T(+2,0)   T(−1,0)
   G→A      E→F
```

- 罗马数字相对 **C 大调**；大写 = 大三和弦，小写 = 小三和弦；`7` = 属七，`maj7` = 大七，`m7` = 小七。
- 和弦名：大写字母 = 大三（`C`），小写 = 小三（`a`）；带七、九时写全称（`Dm7`、`G7`、`Cmaj7`）。
- 三行用等宽字体（Courier New）严格对齐，**箭头和变换符号落在两个和弦之间**。

**变换符号只有三种**（见附录 A.8）：

| 符号 | 键盘上看起来 | 几何上是 | 什么时候用 |
|---|---|---|---|
| `T(a,b)` | 整个手型平移 | 平移 = 移调 | 大 → 大，小 → 小 |
| `P` `L` `R` | 两个键不动，一个键换位 | 绕公共边中点转 180° | 大 ↔ 小，共用两个音 |
| `⟲X` | 一个键不动，手型转半圈 | 绕公共音 X 转 180° | 大 ↔ 小，只共用一个音 |

### 页 5 · `shapes` ★ 每个和弦是一个形状
- **标题**：`Every chord is a shape`
- **顶部一行 = 视图切换 + 迷你词典**（公式式写法，不是句子）：
  ```
  key = a note (a plaquette)  ·  corner = a chord (a site)  ·  key edge = a one-note move (a bond)
  ```
  —— 从这一页开始改用**键盘视图**：每个音一个六边形键，三个键交汇的每个角就是一个三和弦（页 4 的小三角形，换了个画法）。
- **主图 = 增长表**（8 个键盘小图，和弦都以 C 为根；左三列看"增长"，右一列看"张力"）：

  |  | 三和弦 | + 七度 | + 九度 | ‖ | 张力 |
  |---|---|---|---|---|---|
  | **大** | `C` △ 三键 | `Cmaj7` 菱形四键 | `Cmaj9` 锯齿五键 | ‖ | `C7` 三角 + 一条直尾巴 |
  | **小** | `Cm` ▽ 三键 | `Cm7` 菱形四键 | `Cm9` 锯齿五键 | ‖ | `Cdim7` 一条直线 |

  每个小图下面标**音名 + 音高类**：

  ```
  C      C E G          0 4 7            Cm     C E♭ G          0 3 7
  Cmaj7  C E G B        0 4 7 11         Cm7    C E♭ G B♭       0 3 7 10
  Cmaj9  C E G B D      0 4 7 11 2       Cm9    C E♭ G B♭ D     0 3 7 10 2
  C7     C E G B♭       0 4 7 10         Cdim7  C E♭ G♭ A       0 3 6 9
  ```

  列与列之间画一个小箭头，标 `+ a third`。
- **增长公式条**（Courier，这一页的核心）：
  ```
  thirds alternate    4 3 4 3   →  zig-zag   →  n thirds = n − 1 triangles
  two m3 in a row     4 3 3     →  straight  →  m3 + m3 = a tritone
  all m3              3 3 3 3   →  a straight line that wraps  →  only 3 dim7 chords
  ```
- **收尾一句**：`Zig-zag is stable. Straight is tension.`
- **页脚小字**（诚实声明，**别删**）：`Same lattice, different Hamiltonian: Kitaev has interacting spins, we have one particle hopping.`
- **实现建议**：build-in 三步 —— ① 大三 / 小三两个三角 ② 向右长出七、九（让观众看到菱形变锯齿） ③ 右列属七、减七出现，直线用紫色描一遍。
- **画法**：形状**按格点坐标画**（附录 A.7），不要按音高类高亮，否则格子回绕会点亮一堆重复的键。

### 页 6 · `progressions` ★ 每个和声进行是一个格子变换
- **标题**：`Every progression is a lattice move`
- **上半 = 胶片条**：同一小块键盘画 5 格，演 `I – vi – IV – V – I`，每格高亮当时的三和弦，格与格之间写变换：
  ```
   [C]  ──R──▶  [a]  ──L──▶  [F]  ──T(+2,0)──▶  [G]  ──T(−1,0)──▶  [C]
  ```
  R、L 两格让不动的那两个键保持高亮、换位的那一个键闪一下；两次 T 画成整个手型滑动。
- **下半 = 五条进行公式**（罗马数字三行格式，两栏排）：

  ```
  ① 正格终止 —— 只有平移
   I        IV         V          I
   C   →    F    →     G    →     C
      T(−1,0)   T(+2,0)    T(−1,0)

  ② 五十年代进行 —— 两次翻转，两次平移
   I        vi         IV         V          I
   C   →    a    →     F    →     G    →     C
       R          L       T(+2,0)    T(−1,0)
     G→A        E→F

  ③ ii – V – I —— 绕公共音半转，再平移
   ii       V          I
   d   →    G    →     C
      ⟲D        T(−1,0)
    D stays

  ④ 爵士的 ii7 – V7 – Imaj7 —— 每一步都共用一条边
   ii7        V7         Imaj7
   Dm7   →    G7    →    Cmaj7
       keep D–F    keep G–B
     A→G  C→B     D→C  F→E

  ⑤ 电影配乐的 I – ♭VI —— 两次翻转
   I        (i)        ♭VI
   C   →    c    →     A♭
       P          L
     E→E♭       G→A♭
  ```

- **图例**（三行，同第 1.1 节的表）：
  ```
  T(a,b)   slide the shape              = transpose        major→major, minor→minor
  P L R    two keys stay, one hops      = half-turn about the shared edge
  ⟲X       one key stays, shape spins   = half-turn about the key X
  ```
- **收尾一句**：`Between any two triads: exactly one slide or one half-turn.`
- **注意**：④ 是和页 5 的连接点 —— 七和弦形状更大，所以相邻两个和弦能共用整整一条边（两个音），这就是爵士偏爱七和弦的几何原因。三和弦版的 ③ 只共用一个音。

### 页 7 · `lumatone`
- **作用**：现实中真有人把这个晶格做成了乐器；它就是 Kitaev 的蜂窝；它装得进一块有限的板子，是因为 12 平均律。
- **标题**：`Somebody built the lattice. 12-TET makes it fit.`
- **左图**：一片六边形键（可换 Lumatone 实物照片，注意版权来源）。图上一条标注，**全场诱饵在这里收口**：`Kitaev's honeycomb — one key per plaquette`
  下面一行小标签：`280 hex keys · MIDI only · ≈ a used car`
- **右侧公式条**：
  ```
  just:    (3/2)¹² / 2⁷ = 1.0136 ≠ 1     never closes
  12-TET:  12 × 7 ≡ 0  (mod 12)           closes → a torus
           V − E + F = 24 − 36 + 12 = 0
  ```
- **收尾一句**：`Equal temperament is a periodic boundary condition on harmony.`
- **交接**（最下面一行）：`Or open ours in a browser →`

## 附录 A · 晶格几何与和声公式（已逐条验证）

> **朝向以 app 为准。** 下面是样板用的约定；app 的轴向不同就整体换过来，公式结构不变。

### A.1 Tonnetz（三角格）

```
位置:    x = x0 + i·W + j·W/2 ,   y = y0 − j·H
音高类:  pc(i, j) = (7i + 4j) mod 12      # 0=C, 1=C♯, …, 11=B
```

六个近邻方向：

```
(1, 0)  +7 五度     (−1, 0)  +5 四度
(0, 1)  +4 大三度   (0, −1)  +8 小六度
(1,−1)  +3 小三度   (−1, 1)  +9 大六度
```

### A.2 两种三角形（两种三和弦）

```
up(i,j)   = {(i,j), (i+1,j), (i,j+1)}      音: p, p+7, p+4   → 大三和弦，根音 p
down(i,j) = {(i,j), (i+1,j), (i+1,j−1)}    音: p, p+7, p+3   → 小三和弦，根音 p
```

### A.3 对偶（蜂窝 / 和弦图）

```
up(i,j)   重心 = (x + W/2,  y − H/3)
down(i,j) 重心 = (x + W/2,  y + H/3)

up(i,j) — down(i,j)        竖直   = P   共用五度边      C ↔ c
up(i,j) — down(i−1,j+1)    左上   = R   共用大三度边    C ↔ a
up(i,j) — down(i,j+1)      右上   = L   共用小三度边    C ↔ e
```

### A.4 一个六边形 = 一个音

包含格点 `(i,j)` 的六个三和弦：`up(i,j), up(i−1,j), up(i,j−1), down(i,j), down(i−1,j), down(i−1,j+1)`
以 C 为例：`C –R– a –L– F –P– f –R– A♭ –L– c –P– C`。在键盘视图里，这就是 **C 键的六个角**。

### A.5 环面

```
V = 24 个三和弦,  E = 36 条键,  F = 12 个六边形面
χ = V − E + F = 0   →  环面
```

### A.6 键盘视图（页 5–8）

六边形键的中心排在三角格上：水平间距 `s`，行高 `s·√3/2`，隔行错开 `s/2`；外接圆半径 `R = s/√3`。

```
钢琴模式（样板）:  pc = (i + 12j) mod 12      # 向右 +1 半音
和声模式:          pc = (7i + 4j) mod 12      # 就是 Tonnetz
```

### A.7 和弦形状（页 5，根音 C 放在 (0,0)）

| 和弦 | 音 | 音高类 | 格点坐标 | 形状 |
|---|---|---|---|---|
| `C` | C E G | 0 4 7 | (0,0) (1,0) (0,1) | △ = `up(0,0)` |
| `Cm` | C E♭ G | 0 3 7 | (0,0) (1,0) (1,−1) | ▽ = `down(0,0)` |
| `Cmaj7` | C E G B | 0 4 7 11 | + B (1,1) | 菱形 = `C` △ + `e` ▽，共用 E–G |
| `Cm7` | C E♭ G B♭ | 0 3 7 10 | + B♭ (2,−1) | 菱形 = `c` ▽ + `E♭` △，共用 E♭–G |
| `Cmaj9` | C E G B D | 0 4 7 11 2 | + D (2,0) | 锯齿 = `C` △ + `e` ▽ + `G` △ |
| `Cm9` | C E♭ G B♭ D | 0 3 7 10 2 | + D (2,0) | 锯齿 = `c` ▽ + `E♭` △ + `g` ▽ |
| `C7` | C E G B♭ | 0 4 7 10 | (0,0) (0,1) (1,0) (2,−1) | `C` △ + 尾巴；E–G–B♭ 在小三度轴上成一条直线 |
| `Cdim7` | C E♭ G♭ A | 0 3 6 9 | (0,0) (1,−1) (2,−2) (3,−3) | 沿 (1,−1) 的直线；(4,−4) 又回到 C |

**增长规律**（和弦音按三度叠置的顺序走）：

```
Cmaj9   步长 (0,1) (1,−1) (0,1) (1,−1)    音程 4 3 4 3    锯齿
Cm9     步长 (1,−1) (0,1) (1,−1) (0,1)    音程 3 4 3 4    锯齿
C9      步长 (0,1) (1,−1) (1,−1) (0,1)    音程 4 3 3 4    中间两步同向 → 拉直
Cdim7   步长 (1,−1) × 4                   音程 3 3 3 3    全直，每 4 步回原点
```

- 三度交替 → 锯齿 → **n 个三度扫出 n − 1 个三角形**（三和弦 1 个，七和弦 2 个，九和弦 3 个）。
- 连着两个小三度 → 路径拉直 → 直线两端相距一个三全音（`m3 + m3 = 6`）。属七和弦的 E–G–B♭、G7 的 B–D–F 都是这条直线（导音三和弦）。
- 减七全是小三度 → 一条回绕的直线，12 个音只分成 3 条这样的线 → **只有 3 个不同的减七和弦**。
- （备用，不上幻灯片）增三和弦全是大三度 → 沿 (0,1) 的直线，每 3 步回原点 → 只有 4 个。

### A.8 变换（页 6）

**平移 = 移调**：

```
T(a,b):  (i,j) → (i+a, j+b)        pc → pc + 7a + 4b
T(−1,0): 上行四度（C → F, G → C）   T(+2,0): 上行全音（F → G）
```

**半转 = 转位（inversion）**。绕点 c 转 180°：`(i,j) → (2c_i − i, 2c_j − j)`，对音高就是 `pc → k − pc`：

```
P : C → c    绕 C–G 边中点     pc → 7 − pc      E → E♭
L : C → e    绕 E–G 边中点     pc → 11 − pc     C → B
R : C → a    绕 C–E 边中点     pc → 4 − pc      G → A
⟲D: d → G    绕 D 点           pc → 4 − pc      D 不动
```

一般地：`P = pc → (根 + 五) − pc`，`L = pc → (三 + 五) − pc`，`R = pc → (根 + 三) − pc`。它们看起来像"沿公共边翻过去"，严格说是绕公共边中点转 180° —— 这才是整个格子（连音名一起）的对称操作。

**定理**（给物理听众的彩蛋，已验证）：移调与转位（T/I 群，即二面体群 D₁₂）在 24 个三和弦上**单传递地**作用 —— 任意两个三和弦之间，恰好有**一个**平移或半转把一个变成另一个。

### A.9 五条进行的画图坐标（页 6）

```
①  C = up(0,0)  →T(−1,0)→  F = up(−1,0)  →T(+2,0)→  G = up(1,0)  →T(−1,0)→  C
②  C = up(0,0)  →R→  a = down(−1,1)  →L→  F = up(−1,0)  →T(+2,0)→  G = up(1,0)  →T(−1,0)→  C
③  d = down(2,0) = {D(2,0), A(3,0), F(3,−1)}  →⟲D(2,0)→  G = up(1,0)  →T(−1,0)→  C
④  Dm7 = {D(2,0), A(3,0), F(3,−1), C(4,−1)}
    G7  = {G(1,0), B(1,1), D(2,0), F(3,−1)}          Dm7 ∩ G7   = D–F  (一条边)
    Cmaj7 = {C(0,0), E(0,1), G(1,0), B(1,1)}         G7 ∩ Cmaj7 = G–B  (一条边)
⑤  C = up(0,0)  →P→  c = down(0,0)  →L→  A♭ = up(0,−1) = {A♭(0,−1), E♭(1,−1), C(0,0)}
```

### A.10 两种视图是同一张图

- 键盘视图里，**键的中心 = Tonnetz 的顶点**（音），**键的边界 = 一张蜂窝**。
- 蜂窝的每个顶点（三个键交汇的角）正好碰到三个互相相邻的键 = 一个三角形 = **一个三和弦**。
- 所以：等距键盘 = Kitaev 的蜂窝，**每个 plaquette 里放一个键**；Kitaev 的格点 = 键的角 = 和弦；Kitaev 的键 = 键的边 = 一步 P / L / R。
