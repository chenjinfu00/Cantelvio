本地曲谱文件夹

选一个你自己放曲谱的文件夹，Volta 就把里面的 PDF 当成曲谱库来读。曲谱不上传，也不经过任何服务器——这个页面本身就是整个应用。

文件夹该怎么放
我的曲谱/
├ 肖邦/练习曲/练习曲 Op.10 No.1/
│    钢琴独奏 · 1fdb0518.pdf
│    钢琴与小提琴 · 6f8ea4b2.pdf
│    练习曲.mid
└ 曲谱库数据/
     catalog.json
     manifest.json
  • 一首曲子一个文件夹，同一首的不同版本 PDF 放在一起。
  • 同一层里的 MIDI 文件会被当成这首曲子的源文件，可以在应用里直接播放。
  • 曲谱库数据/manifest.json 把每份 PDF 的 SHA-256 对应到它的相对路径，catalog.json 写曲名、作曲家、编曲。两份都是纯文本，可以自己写，也可以用仓库里的脚本扫描生成。
  • 完整字段说明和生成脚本：GitHub 上的 README。

HOW VOLTA LISTENS

让曲谱认识你的演奏

  1. 导入 PDF。 从 IMSLP 下载到本机，然后选择文件。页码使用 PDF 的实际页码，包含封面。
  2. 学习一遍。 导入同一版本的录音，在每页开头标记位置；或开启“用麦克风学习”，弹奏时手动翻页。开始前先选好第一页。
  3. 再次演奏。 回到学习的起始页，点击“开始聆听”。系统通过音乐的音高特征对齐参考演奏，跟随速度变化。

翻页点、版本偏好、书签和批注保存在当前设备；选择了支持写入的曲谱库后，可用批注工具栏的“同步”写回曲谱库。清除网站数据会移除这些本机记录。这是一版实验性听谱工具。重复乐句、很弱的声音或演奏与参考差异较大时，可能需要手动帮助定位。安静时会等待，意见不明确时不会自动跨页。扫描 PDF 尚不进行音符识别。

请通过 HTTPS 页面使用；iPad 可用 Safari，并在需要自动翻页时允许麦克风。耳机听参考录音时请关闭“开始聆听”。
