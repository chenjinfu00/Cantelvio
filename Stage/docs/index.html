 HOW VOLTA LISTENS

使用指南

选择包含「曲谱库数据/catalog.json」和「manifest.json」的曲谱根文件夹。

  1. 打开曲谱。 在左侧曲谱库选择作品，或点“临时打开 PDF”。临时曲谱支持本机文件和 IMSLP PDF 直链，不加入曲谱库、最近访问或离线副本。
  2. 学习一遍。 导入 MIDI 或同一版本的录音，在每页开头标记位置；或开启“用麦克风学习”，弹奏时手动翻页。开始前先选好第一页。
  3. 再次演奏。 回到学习的起始页，点击“开始聆听”。系统通过音乐的音高特征对齐参考演奏，跟随速度变化。翻页前约 3 秒显示倒计时进度条；停奏或识别不稳时提示暂停。

翻页点、版本偏好、书签和批注保存在当前设备。需要备份时，点击右侧批注工具栏最下方的导出图标，再保存到「曲谱库数据／批注」；网页不会直接写入曲谱文件夹。清除网站数据会移除尚未导出的本机记录。这是一版实验性听谱工具。重复乐句、很弱的声音或演奏与参考差异较大时，可能需要手动帮助定位。安静时会等待，意见不明确时不会自动跨页。扫描 PDF 尚不进行音符识别。

请通过 HTTPS 页面使用；iPad 可用 Safari，并在需要自动翻页时允许麦克风。耳机听参考录音时请关闭“开始聆听”。查看完整使用说明 ↗
