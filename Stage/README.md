# Volta · 听谱翻页

一个无需 MIDI 输入的曲谱阅读与排练工具。导入 PDF，学习一遍参考演奏并标记翻页点，再通过麦克风跟随实际演奏。支持手动翻页、演出模式及触控笔批注。

## 网站与仓库

入口：<https://chenjinfu00.github.io/volta/>，自动转到 <https://volta-chenjinfu.netlify.app/volta/>。iPad 请把后者添加到主屏幕；生产站仅使用 Volta 密码，不需要 Netlify 账号。

本仓库独立维护 Volta，个人主页仓库不包含这里的文件。网站源文件位于 `docs/`。私密云端版本在 Netlify 上使用服务端密码验证，不能只部署静态文件来保护 PDF。

GitHub Pages 设置：从分支部署，选择 `main` 分支的 `/docs` 目录。

## 数据范围

- 当前发布目录不再包含公开 PDF；701 份曲谱在 Netlify 私有存储中，包含肖邦第二钢琴协奏曲 Op.21 波兰国家版。旧版 10 份试用 PDF 已移至忽略发布的本地存档，原件保留。
- 手写批注先保存在各自浏览器，云端版可在设置中手动“更新批注”；上次使用的版本和学习记录不跨设备同步。
- 用户自行导入的 PDF 和参考音频仅在当前设备处理，不会加入公开谱库。
- 清除浏览器网站数据会移除本机记录，请定期导出批注备份。
- 曲谱文件保留原始内容，各自版权及来源声明不变。

## 检查

运行 `npm test` 检查应用行为、资源相对路径与私人数据隔离。上线只做入口与鉴权的必要检查；不自动重新校验整套 PDF。

## 本地合并谱库（不随仓库发布）

- 本机 `本地曲谱/曲谱/` 保存 701 份内容唯一的 PDF 副本，按游戏／作曲家和体裁建子目录。网页也可按风格、年代浏览。当前归并为 579 个曲目／合集；不确定的归属保留明确标记。
- 来源为原谱库 660 份 PDF 与已备份的 Piascore 132 份：Piascore 内部去重为 129 份，其中 88 份已有，新增 41 份。不再尝试导出 iPad 列表的 204 项。
- 完全相同内容只复制一份，选择修改时间最新的来源，并逐一验证 SHA-256。不同内容的版本保留；默认最新版本，已保存的版本偏好优先。原始文件及备份不删除、不改写。
- `node scripts/preview.mjs 4320 --lan --library` 启用本地谱库；不带 `--library` 是不附带 PDF 的阅读器。iPad 与 Mac 同一局域网时访问 Mac 的 4320 端口。该本地服务没有登录，请仅在可信局域网使用，不做公网端口转发。
- 本地索引、整理副本、来源对应表均位于已被 Git 忽略的 `本地曲谱/`，不会进入 `docs/`、离线应用资源清单或 GitHub Pages。HTTP 局域网版不支持浏览器的安全上下文离线下载和麦克风功能；阅读与批注可用。
- `scripts/build-local-library.mjs <旧项目的 local_data 目录>` 可重复校验并生成此本机收藏，需本机的 `本地曲谱/metadata.json`。启动服务只允许按内容 ID 读取已登记的 PDF，不暴露来源路径和合并审计文件。

## 沉浸阅谱与离线

- 轻触左／右侧 40% 区域翻页，中间 20% 显示工具；从左边缘向内划出谱架，从顶部向下划出工具。
- 默认“适配屏幕”使用每一页全部非白标记的保守边界，外加 12 PDF 点余量，并合并已有手写笔迹边界。701 份、11,259 页已离线预检。保持比例、不裁切检测内容；未经预检的页面保留整页，最小缩放靠下对齐。设置可关闭保护并铺满，但可能裁切。检查不是音符识别，无法修复原扫描的缺失；极浅标记、扫描黑框需要实际读谱确认。
- 双指缩放只变换纸张和批注，松开后做一次高清重绘；菜单和浮动工具不随谱面缩放。任一手指被系统取消时不提交缩放。
- 翻页保留拖动后的对齐位置，按谱本、横竖屏、适配／放大模式保存在当前浏览器；预览细化不重置位置。位置按照页面尺寸比例迁移并限制在下一页的可移动范围内。设置中可关闭记忆或还原位置。
- 普通阅谱时 Pencil 落笔自动书写，手指继续翻页；浮窗上方把手可拖动，松开吸附到最近的屏幕边缘，横竖屏分别记忆位置，选项朝屏幕内部展开。
- 笔尖接触谱面并停稳 1 秒后切换笔／橡皮。移动会重新计时，允许小幅抖动；写完不抬笔停住也能切换，并保留已写笔迹。孤立长按不留下墨点，抬笔后使用新工具。这是网页内的笔尖接触手势，不是悬停、笔杆双击或挤压。演出模式隐藏并停用批注。
- 顶部只保留版本、布局、缩放、翻页和演出入口；左侧集中谱库、导入、离线保存及默认折叠的自动翻页准备。
- 主屏幕适配 v5：独立于 PDF 引擎提前启动阅读外壳，冷启动、回到前台与旋转后进行有限次数的高度复测。只有整屏宽度一致的 iPad 主屏幕应用，才补偿最多 96 CSS 像素的高度缺口；不硬编码原生屏幕分辨率，不放大较小窗口或键盘遮挡区域。主屏幕外壳与启动背景统一为深色。设置里的“屏幕适配诊断”显示实际采用的尺寸，仅在本机显示、不上传。补偿属于有边界的兼容处理；iPadOS 在网页之外绘制的区域仍需真机确认。
- 主屏幕适配 v6：在上述高度补偿之外，文档与 body 本身使用完整尺寸，谱架及浮动工具改为相对文档定位，不再依赖主屏幕模式可能被裁切的 fixed 容器。诊断新增文档、页面、谱架、阅谱区的实际上下边界及底边命中检查。若各层已铺满但屏幕仍被系统遮盖，不能将模拟测试当成真机问题已修复。
- 设置 → 显示区域提供 ±80 CSS 像素的底边微调，仅在主屏幕模式使用，横竖屏分别记忆。“还原自动尺寸”只清除当前方向的校准，不更改曲谱或批注。实际可绘制区域若被系统裁切，单纯增加高度无法保证有效。
- 演出模式无常驻菜单，中央轻触召回工具，5 秒自动收起；方向键、PageUp／PageDown、空格与兼容踏板仍可翻页。
- 主题默认蓝色；设置页集中调节主题、轻触灵敏度、预读及演出全屏请求。
- 预读当前页前后各 5 页：即将翻到的页采用高清缓存，较远页采用轻量预览。高清画布不超过 5 项／约 1400 万像素（切换时可短暂超出以保留旧页），预览不超过 12 项／350 万像素。每页高清最多 400 万像素；批注画布另计。释放 PDF.js 页面解码对象，避免长期翻阅持续积累。
- 默认打开当前谱子后自动保存该 PDF，可在设置关闭。下载和 SHA-256 校验分段进行，不为大谱创建整份 ArrayBuffer；失败不替换已有离线副本。只有应用缓存完成、PDF 下载完整并校验成功才提示离线可用。设置页可打开或移除离线副本，不删除原谱与批注。
- 离线存储按设备和浏览器隔离。Safari 可添加到主屏幕；系统可能回收存储，网站无法保证永久保留数据或隐藏所有 iPadOS 状态栏。网站不能阻止系统通知。

本地预览：`npm run preview`，访问 `http://localhost:4318/volta/`。发布前运行 `npm run build` 与 `npm test`。

局域网预览：`node scripts/preview.mjs 4320 --lan`，在同一网络的 iPad 打开控制台显示的地址。HTTP 局域网支持阅谱和批注；麦克风、离线应用缓存等需使用 HTTPS 网站或本机 localhost。

离线应用由 `docs/sw.js` 版本管理。修改应用资源后须更新其中的 `SHELL` 版本号并重新构建缓存清单；更新不会中断打开的谱页，关闭同一网站的所有标签页再打开后使用新缓存。应用预缓存不含 PDF；只保存用户打开的曲谱，不自动下载整个谱库。

## 私密云端部署（Netlify）

- `node scripts/build-netlify.mjs` 生成 `dist/volta`：排除 `scores/`、`library/`、`fit/`，不包含 PDF、私人目录、口令或批注。平台团队访问保护必须与应用内登录分别验证；不要把受平台保护的 401 当作应用鉴权测试通过。
- `node scripts/set-cloud-password.mjs` 在交互终端读取密码且不回显，仅把随机盐 + PBKDF2-SHA256（310,000 次）的校验值写入独立的服务端私有 `volta-auth-config` 存储，回读核对。没有公开读取路由，不依赖付费的环境变量作用域。
- 设备凭据是 32 字节随机数，放入 HttpOnly、Secure、SameSite=Strict 的 Cookie，有效期一年；服务器仅保存凭据哈希。每次下载 PDF、清单、适配边界或读写云端批注都检查设备是否有效、过期或已撤销。新设备仍需密码。
- `node scripts/upload-private-library.mjs` 上传全部 701 份，包括两份超过 100 MB 的 PDF。私有存储按内容 ID 平铺，每个数据块 2 MiB；6 个固定异步通道按完成顺序领取下一份，无整批屏障。每份文件独立校验、完成后串行追加断点；瞬时错误重试、鉴权错误停止领取并排空已在途任务。全部完成后才发布私有目录。
- `node scripts/verify-private-library.mjs` 检查目录、全部 PDF 分块及适配记录是否齐全，完整回读并校验两份大 PDF。
- “更新批注”先排空本机保存，再进行带 ETag 的三方合并；冲突重新读取，不直接覆盖另一设备的笔迹。设置保留通用批注导入／导出功能。本次按用户要求直接切换入口，不迁移或处理旧批注，也不删除旧浏览器数据。
- 已下载的离线 PDF 和批注不能被设备撤销远程收回；请保护设备锁屏，不把“记住设备”用于公共电脑。旧版公开的 10 份 PDF 存在于 Git 历史中；迁移当前部署不能保证清除已公开的副本，重写历史需另行确认。
- 单元测试覆盖失败下载、哈希不符、不完整响应、串行等价与偏斜队列、真实指针处理、批注迁移、并发保存与冲突合并。真实 iPad 主屏幕离线和手写体验仍需设备上验收，桌面尺寸模拟不能替代。

增量 SHA-256 来自 `@noble/hashes`，可用 `node scripts/build-hash.mjs` 更新浏览器构建；随附其许可证。
