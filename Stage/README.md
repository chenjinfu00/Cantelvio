# Volta · 听谱翻页

一个无需 MIDI 输入的曲谱阅读与排练工具。导入 PDF，学习一遍参考演奏并标记翻页点，再通过麦克风跟随实际演奏。支持手动翻页、演出模式及触控笔批注。

## 网站与仓库

网站目标地址：<https://chenjinfu00.github.io/volta/>。

本仓库独立维护 Volta，个人主页仓库不包含这里的文件。网站源文件与公开试用曲谱位于 `docs/`，无需服务器、登录或安装依赖。

GitHub Pages 设置：从分支部署，选择 `main` 分支的 `/docs` 目录。

## 数据范围

- 公开谱库仅包含选定的 10 份试用 PDF，包括肖邦第二钢琴协奏曲 Op.21 波兰国家版。
- 手写批注、上次使用的版本和学习记录仅保存在各自浏览器，不上传、不跨设备同步。
- 用户自行导入的 PDF 和参考音频仅在当前设备处理，不会加入公开谱库。
- 清除浏览器网站数据会移除本机记录，请定期导出批注备份。
- 曲谱文件保留原始内容，各自版权及来源声明不变。

## 检查

运行 `npm test` 校验公开文件、曲谱数量与哈希、资源相对路径及个人数据隔离。
