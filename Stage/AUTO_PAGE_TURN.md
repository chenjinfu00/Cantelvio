# MIDI 与录音自动翻页

2026-09-28，已发布至 AIgimon。入口与操作见 README 的“跟随 MIDI 或录音自动翻页”。

## 肖邦示例

- 波兰国家版第 31 册，双钢琴，第二钢琴协奏曲 Op.21 第一乐章。
- PDF 指纹：`88345f8f0f0a7270773ecaeed9fc02cb77b8c989ffd6664609b6051116a3dd72`。
- MIDI：Robert Finley，`Chopin Op.21 - I. Maestoso - Robert Finley.mid`；指纹 `105f564a1f7bda5529734ccbc046a72851a57153fb5d47b91539e272513b5fa3`。
- PDF 第 13 页为起点，第 14–48 页共 35 个翻页点。第 17 页按第 71 小节独奏进入定位；该页最前面另有两小节休止。第 33 页按第 214 小节休止后的首个音定位。
- 翻页点逐页查看谱面后按 MIDI 音符起奏位置对齐。MIDI 自身的时间网格和谱上小节号不同，未按固定 BPM 推算页码。
- 私人曲谱文件夹内已保存 MIDI、`Chopin Op.21 - I - Volta 翻页点.json`、测试录音与来源说明。应用源码只包含翻页位置，不包含国家版 PDF、MIDI 或测试录音。

MIDI 来源：[Metronimo](https://www.metronimo.com/fr/midi/index.php?page=Chopin)；[演奏者条目及使用说明](https://www.classicalmidiconnection.com/finley.html)。

## 行为

MIDI 先在浏览器用钢琴采样渲染为可试听的声音，再使用与录音、麦克风相同的音高特征提取器。每次只渲染 20 秒，避免一次生成整个乐章的浮点音频。试听 WAV 在完成或取消学习时释放；持久保存的是声音特征与翻页点。

倒计时按照最近的音乐推进速度估计，提前约三秒出现。实际翻页需要连续的稳定匹配，计时器本身不触发翻页。安静、匹配不稳定或匹配位置停住时冻结提示；手动翻页重新定位，并给手动操作 2.5 秒优先时间。演出模式及界面隐藏时提示仍可见。

导出的 JSON 只有页码、参考时间、可选小节号和休止区间，不带音频或声音特征。PDF 与参考文件均按完整指纹检查，防止把不同版本、不同演奏的秒数混用。

## 当前边界

录音测试和测试麦克风已经通过，尚未在真实房间、真实钢琴和 iPad 麦克风上验证。上述整乐章检查证明翻页顺序可完成，不等于每一个真实演奏边界都经过人工听审。重复段、跳奏、背景音乐、很弱的音量仍可能需要手动重新定位。

此示例保留乐队声部，面向完整录音或双钢琴。仅弹独奏、长段省略、不同版本等情况需重新检查参考。普通 MIDI 乐器统一用钢琴音色生成参考，尚未还原原曲的管弦音色与踏板。
