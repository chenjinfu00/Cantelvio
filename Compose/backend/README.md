从项目根目录运行 `npm start`，或者从 `frontend/` 运行 `npm start`。根目录 `server.mjs` 是旧命令 `node server.mjs` 的兼容入口。模型权重不会因 UI 修改自动替换；新检查点仍需单独验证与导出。
