试听编辑生成和声演奏

从一段旋律，写到完整曲谱。

用 Transformer 改进自动作曲的和声与旋律：生成、试听、比较，再在编辑器里亲手修改、回放和导出。

体验曲谱编辑与回放 试听模型结果 浏览器内生成演示
Compose→Score→StageHarmony

四个工作台通过音乐文件连接。在线可以直接试听、编辑和读谱；完整的旋律配伴奏在电脑上运行。

第一次使用

1 · 先听一段

同一旋律的不同模型结果可直接试听，并查看生成方式与局限。

打开试听库 →
2 · 打开示例曲谱

修改音符、回放，再导出 MIDI 或 PDF。也可以导入自己的 MusicXML。

开始编辑 →
3 · 用自己的 PDF 演奏

在 Stage 选择“临时打开 PDF”，即可读谱和批注。自动翻页需先学习参考演奏。

打开演奏工作台 →

Compose

生成

浏览器内运行的联合模型：旋律、和声、低音与配器。完整的伴奏与连续演奏使用本机 Python 服务（见 GitHub）。

试用 →

打开 →

打开 →

Stage

演奏

PDF 读谱、演奏跟随与自动翻页（麦克风仅在本机处理）。
